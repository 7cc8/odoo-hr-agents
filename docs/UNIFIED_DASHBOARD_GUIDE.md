## 📖 طرق الاستخدام

### 🎯 الطريقة 1: محادثة عادية

**الخطوات:**
1. اكتب سؤالك في صندوق الدردشة أسفل الشاشة
2. اضغط **Enter** أو زر الإرسال (**➤**)
3. سراج يستجيب عبر الوكلاء المناسبين

**أمثلة على الأسئلة:**
- "ما هي الوكلاء المتاحين في النظام؟"
- "كيف يمكنني رفع ملف Excel؟"
- "اشرح لي عملية الفحص التجريبي"
- "ما هي الشروط المطلوبة لإنشاء موظف؟"

---

### 📁 الطريقة 2: رفع ملف ومعالجة تلقائية

**الخطوات:**

#### أ) رفع الملف
1. انتقل إلى قسم "رفع ملف Excel" على اليمين
2. اضغط على منطقة الرفع أو اسحب الملف عليها
3. اختر ملف بصيغة `.xlsx` أو `.xls` (حتى 2MB)

#### ب) المعالجة التلقائية
4. اضغط زر **"🚀 معالجة الملف عبر الوكلاء"**
5. شاهد خط المعالجة (Pipeline) يعمل خطوة بخطوة:
   - **📋 المحلل**: قراءة بنية الملف
   - **✓ المدقق**: التحقق من صحة البيانات
   - **🔍 المحاكاة**: فحص تجريبي بدون كتابة
   - **👤 الموافقة**: اعتماد السجلات المقبولة تلقائياً
   - **✍️ الكاتب**: الكتابة النهائية في Odoo

#### ج) النتائج
6. النتائج تظهر في:
   - **الشات**: رسائل من كل وكيل مع التفاصيل
   - **Pipeline**: تغيير حالة كل خطوة (معلق → قيد التنفيذ → مكتمل)
   - **الإحصائيات**: تحديث الأرقام في الأعلى

---

### 💬 الطريقة 3: رفع ملف + محادثة

**السيناريو:** تريد معالجة ملف مع توجيهات خاصة

**الخطوات:**
1. ارفع ملف Excel من قسم الرفع
2. انتظر حتى يظهر اسم الملف في المعاينة
3. اكتب في الشات أحد الأوامر التالية:
   - "افحص هذا الملف"
   - "قم بمعالجة الملف المرفق"
   - "تحقق من البيانات في الملف"
4. سراج يستقبل الملف ويعالجه عبر الوكلاء
5. يشرح كل خطوة ويعرض النتائج في المحادثة

## 🎨 مكونات الواجهة

### 1️⃣ قسم البطل (Hero)
```
سراج HR Agents
نظام ذكي متكامل لأتمتة إدارة الموارد البشرية
```
- أزرار الانتقال السريع للشات أو رفع الملفات

### 2️⃣ بطاقات الإحصائيات
```
[8 وكلاء]  [42 سجلات]  [95% نجاح]  [12s]
```
- تحديث مباشر بعد كل عملية معالجة

### 3️⃣ الشات (Chat)
- **الرسائل**: سجل المحادثة الكامل
- **الوكلاء**: كل رسالة تعرض اسم الوكيل المتحدث
- **الصور الرمزية**: 👤 للمستخدم، 🤖 للوكلاء
- **الإدخال**: صندوق نص مع زر إرسال

### 4️⃣ رفع الملفات
- **منطقة الرفع**: Drag & Drop أو Click to Upload
- **المعاينة**: عرض اسم وحجم الملف المختار
- **التحقق**: فحص تلقائي للنوع والحجم
- **الإزالة**: زر **✕** لإلغاء الاختيار

### 5️⃣ خط المعالجة (Pipeline)
```
📋 المحلل      → معلق / قيد التنفيذ / مكتمل ✓
✓ المدقق       → معلق / قيد التنفيذ / مكتمل ✓
🔍 المحاكاة    → معلق / قيد التنفيذ / مكتمل ✓
👤 الموافقة    → معلق / قيد التنفيذ / مكتمل ✓
✍️ الكاتب      → معلق / قيد التنفيذ / مكتمل ✓
```
- **الخطوة النشطة**: تضيء باللون الأخضر مع تأثير نبض (pulse)
- **الخطوة المكتملة**: علامة ✓ خضراء
- **الخطوة المعلقة**: رمادي فاتح

## 🛠️ الوكلاء الثمانية

### 1. سراج (Seraj) - Meta Orchestration
- **الدور**: منسق عام ومدير المحادثة
- **المهام**: توجيه الطلبات، تنسيق الوكلاء، الرد على الأسئلة

### 2. فحّاص (Fahas) - Tools Agent
- **الدور**: مزود الأدوات والوظائف
- **المهام**: استدعاء أدوات Odoo، تنفيذ العمليات المساعدة

### 3. كاتب (Katib) - Execute Agent
- **الدور**: منفذ العمليات النهائية
- **المهام**: الكتابة في Odoo، إنشاء السجلات

### 4. مُدَقِّق (Mudaqqiq) - Verify Agent
- **الدور**: مدقق البيانات والقوانين
- **المهام**: التحقق من صحة البيانات، تطبيق القوانين السعودية

### 5. حارس (Hares) - Guard Agent
- **الدور**: حارس الأمان
- **المهام**: منع العمليات الخطيرة، التحقق من الصلاحيات

### 6. مُصلِح (Musleh) - Heal Agent
- **الدور**: مصلح الأخطاء
- **المهام**: اقتراح حلول، إصلاح البيانات التالفة

### 7. سِجِل (Sijil) - Log Agent
- **الدور**: مسجل الأحداث
- **المهام**: تسجيل جميع العمليات، حفظ السجل التدقيقي

### 8. مُوَفِّق (Muwaffaq) - Match Agent
- **الدور**: مطابق البيانات
- **المهام**: مطابقة السجلات، البحث عن التكرارات
