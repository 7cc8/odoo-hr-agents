Dry-run report

مبني ومختبر

Approval schema

يربط الموافقة بنفس الملف والـ run والصفوف المقبولة.

مبني ومختبر

Writer

يعيد التحقق وينشئ الموظف ويسجل النتيجة، في test DB فقط.

مبني ومختبر

Write gateway

يسمح فقط بـ create وread ويمنع write وunlink والبيئات غير المصرح بها.
