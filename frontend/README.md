# واجهة سراج

تُحمّل لوحة التشغيل من `dashboard.html`. تتولى `js/dashboard.js` المحادثة والتنقل والاستيراد والإعدادات. يربط `js/hr-services.js` نماذج خدمات الموارد البشرية بمسارات الخادم، ويتولى `js/moxen-despliegue.js` حركة تفاصيل الوكلاء. أنماط الواجهة في `css/dashboard.css`.

يُفتح دليل الخدمات مباشرة من `/?view=services`. تتبع الحقول المطلوبة عقد الخدمة المنشور في `/openapi.json`. تتطلب إجراءات الاعتماد مسودة صالحة ورمز اعتماد صادر من الخادم.
