# Galleta · Moxen

Tres botones con el mismo peso, las categorías opcionales apagadas de partida y, en «Personalizar», cada una con su interruptor y su descripción, en una tarjeta que se despliega con un resorte sin saltos de alto. Al guardar, la tarjeta se encoge hasta un botón redondo con una galleta que gira, suelta migas y muestra un ✓, con un mordisco por cada categoría rechazada.

## Qué trae

- `index.html` — la demostración
- `galleta.css`
- `galleta.js`
- `LICENCIA.txt` — lo que puedes y no puedes hacer con él.

Dependencias: Ninguna.

## Cómo usarlo

1. Abre `index.html` en el navegador para verlo funcionando.
2. Copia `galleta.css` y `galleta.js` a tu proyecto y enlázalos como en `index.html`.
3. Copia el marcado de la demostración (lo que hay dentro de `<main>`) o
   aplícalo a tus propios elementos.

Los colores y medidas están en variables CSS al principio de los estilos, y el
código está comentado en español.

## Quick start (English)

Three equally weighted buttons, optional categories off by default and, under “Customize”, a switch and a description for each one, in a card that unfolds on a spring with no jumps in height. On save the card shrinks into a round button holding a cookie that spins, drops crumbs and shows a ✓, with a bite taken out for every category you turned down.

Open `index.html` to see it working, then copy the CSS and JS files into your
project and link them the way `index.html` does.
