# Pregunta · Moxen

Selector de modelo con descripciones, adjuntos que entran como chips con resorte y sugerencias en tarjetas. Al enviar, la caja baja con FLIP y la respuesta se escribe por bloques —párrafo, lista y código resaltado— con un cursor que destella, botón de detener, copiar con ✓ y regenerar.

## Qué trae

- `index.html` — la demostración
- `pregunta.css`
- `pregunta.js`
- `img/` — las fotos de la demostración (Unsplash; reemplázalas por las tuyas)
- `CREDITOS.md` — autor y enlace de cada foto
- `LICENCIA.txt` — lo que puedes y no puedes hacer con él.

Dependencias: Ninguna.

## Cómo usarlo

1. Abre `index.html` en el navegador para verlo funcionando.
2. Copia `pregunta.css` y `pregunta.js` a tu proyecto y enlázalos como en `index.html`.
3. Copia el marcado de la demostración (lo que hay dentro de `<main>`) o
   aplícalo a tus propios elementos.

Los colores y medidas están en variables CSS al principio de los estilos, y el
código está comentado en español.

## Quick start (English)

A model picker with descriptions, attachments that spring in as chips and suggestion cards. On send the box glides down with FLIP and the answer types out in blocks — paragraph, list and highlighted code — behind a glinting cursor, with a stop button, copy with a checkmark and regenerate.

Open `index.html` to see it working, then copy the CSS and JS files into your
project and link them the way `index.html` does.
