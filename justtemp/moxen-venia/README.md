# Venia · Moxen

Tres tarjetas de permiso (avisos, ubicación y cámara) con un anillo de estado: al pulsar «Activar» cae desde el candado, con resorte, una vista previa del cuadro nativo. Si permites, el anillo se cierra con un ✓ y la tarjeta lo demuestra; si denegas, pasa a ámbar y una guía de tres pasos señala el candado, que abre los permisos del sitio para recuperarlo.

## Qué trae

- `index.html` — la demostración
- `venia.css`
- `venia.js`
- `LICENCIA.txt` — lo que puedes y no puedes hacer con él.

Dependencias: Ninguna.

## Cómo usarlo

1. Abre `index.html` en el navegador para verlo funcionando.
2. Copia `venia.css` y `venia.js` a tu proyecto y enlázalos como en `index.html`.
3. Copia el marcado de la demostración (lo que hay dentro de `<main>`) o
   aplícalo a tus propios elementos.

Los colores y medidas están en variables CSS al principio de los estilos, y el
código está comentado en español.

## Quick start (English)

Three permission cards (notifications, location and camera) with a status ring: pressing “Turn on” drops a preview of the native dialog from the padlock on a spring. Allow it and the ring closes with a ✓ while the card proves it works; deny it and it turns amber with a three-step guide pointing at the padlock, which opens the site permissions to recover it.

Open `index.html` to see it working, then copy the CSS and JS files into your
project and link them the way `index.html` does.
