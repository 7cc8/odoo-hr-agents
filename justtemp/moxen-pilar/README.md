# Pilar · Moxen

Arrastrar el borde de un encabezado cambia el ancho con una guía azul que cruza la tabla entera (doble clic lo ajusta al contenido) y arrastrar el encabezado levanta la columna como una lámina mientras las demás se apartan. La chincheta fija la columna con una sombra al desplazar, el menú «Columnas» pliega y despliega, la densidad cambia las filas en ola y «Restablecer» lo devuelve todo con un vuelo y un ✓ azul.

## Qué trae

- `index.html` — la demostración
- `pilar.css`
- `pilar.js`
- `LICENCIA.txt` — lo que puedes y no puedes hacer con él.

Dependencias: Ninguna.

## Cómo usarlo

1. Abre `index.html` en el navegador para verlo funcionando.
2. Copia `pilar.css` y `pilar.js` a tu proyecto y enlázalos como en `index.html`.
3. Copia el marcado de la demostración (lo que hay dentro de `<main>`) o
   aplícalo a tus propios elementos.

Los colores y medidas están en variables CSS al principio de los estilos, y el
código está comentado en español.

## Quick start (English)

Dragging a header edge resizes the column with a blue guide that crosses the whole table (double-click fits it to its content), and dragging the header lifts the column like a sheet while the others make way. The pin fixes a column with a shadow when scrolling, the “Columns” menu folds and unfolds, density changes the rows in a wave and “Reset” sends everything back with a flight and a blue ✓.

Open `index.html` to see it working, then copy the CSS and JS files into your
project and link them the way `index.html` does.
