# 👑 مقر شركة سراج الذكي لوكلاء الموارد البشرية | Odoo HR HQ

مجلد مستقل وشامل يحتوي على منظومة مقر شركة سراج البصرية التفاعلية بالكامل بتقنية **MetroCity 16-bit Pixel Art** مع محرك الحوارات الحية ولوحة القيادة التنفيذية (Bento Cockpit) والدليل المعماري.

---

## 📁 محتويات المجلد

| الملف | الوصف والدور |
| :--- | :--- |
| **`index.html`** | الصفحة الرئيسية المستقلة بالكامل للمقر (الخريطة البكسلية + محرك الحوارات + لوحة التحكم + الدليل). |
| **`launch_hq.bat`** | مشغل فوري بنقرة واحدة لأنظمة Windows لفتح المقر مباشرة في المتصفح. |
| **`launch_hq.py`** | سكريبت خادم محلي خفيف (`http://localhost:5174/`) للتشغيل المستقل دون أي تبعيات خارجية. |
| **`metro_sprites_b64.js`** | مكتبة الرسوم والسبرايتات البكسلية بدقة 16-بت (الشخصيات، المكاتب، الشاشات، النباتات، الكراسي المتقابلة). |
| **`metro_avatars.json`** | بيانات الأفاتارات البكسلية لوكلاء الموارد البشرية. |
| **`scripts/`** | سكريبتات وأدوات المحاكاة والربط البرمجي السابقة (`pixel_office_bridge`, `demo_metrocity_agents`, `generate_hq_layout`). |
| **`README.md`** | هذا الدليل التوثيقي الشامل. |

---

## 🏢 خريطة المقر والمكاتب الـ 14

يضم المقر 14 قاعة ومكتباً معمارياً مجهزاً بأرضيات باركيه staggered وسجاد تنفيذي فاخر:

1. **جناح الإدارة العامة (CEO Suite):** مكتب سراج (المدير التنفيذي) ومكتب صوفيا (رئيس الموظفين CoS) على السجاد الملكي الفاخر.
2. **قاعة الاجتماعات الرئيسية (Boardroom):** طاولة اجتماعات كبرى مع كراسي متقابلة وجهاً لوجه وشاشة مؤشرات حية.
3. **مكتب فاحص وسِجل:** استعلام العقود والإقامات وتدقيق سجل المراجعة ورصد الشذوذ.
4. **مكتب مُصلح (Studio):** تشخيص وتنظيف قوالب Master Excel في وضع المحاكاة Dry-Run.
5. **كابينة مُنصت (Recording Booth):** تحليل الأوامر والرسائل الصوتية بتقنية Whisper.
6. **بوابة موصل أودو (Web Room):** مراقبة اتصال XML-RPC وسياق الشركات المتعددة.
7. **مكتب مُدقّق (Academy):** فحص الامتثال لنظام العمل السعودي (المادة 85 والمادة 80).
8. **مستودع المهارات والتوثيق (GitNexus Library):** فحص أثر التعديل وشجرة التبعيات (17,395 رمزاً و 574 مساراً).
9. **مختبر باحث الذاكرة (Memory Lab):** استرجاع الأنماط الناجحة وحفظ الخبرات التراكمية.
10. **مكتب كاتب ومُصدر الخطابات:** بوابات الكتابة المعتمدة في Odoo وإصدار خطابات التعريف.
11. **مكتب مراسل تيليجرام (Mailroom):** الإشعارات العاجلة وملخص الساعة 8:00 صباحاً.
12. **مكتب حارس (Ads/Security Room):** بوابة الأمان وبطاقات الموافقات المعلقة.
13. **مكتب موفّق (Growth Room):** المطابقة الذكية للأسماء والأقسام ومنع التكرار (Fuzzy Match 96.4%).
14. **مكتب محاسب المسيرات (Finance Office):** حساب مسيرات الرواتب ومستحقات نهاية الخدمة والتأمينات.

## ⚡ الميزات والقدرات المدمجة

- **13 سيناريو تعاون حي:** يتحرك فيها الوكيل فعلياً عبر الممرات لزيارة زميله وتبادل حوار من 3 مراحل بصوت مركب وتأثيرات XP عائمة وسجل تدقيق في الأسفل.
- **كراسي متقابلة واقعية:** كراسي قاعة الاجتماعات وكراسي زوار المكاتب تتقابل وجهاً لوجه بفضل سبرايت `chair_back` المطور.
- **وضوح بصري فائق:** لوحات مكاتب بكسلية ذهبية وبحرية عالية التباين بخط Cairo عريض لسهولة القراءة دون تداخل.
- **قمرة قيادة تنفيذية (Bento Cockpit):**
  - بطاقات **ينتظرك (Needs you)** للاعتماد المباشر.
  - قائمة **المسارات الجارية (Running)** مع أشرطة تقدم حية.
  - جدول **فريق العمل (Team)** مع شارات الحالة والمستوى.
  - تفريغ كامل لـ **اجتماع الصباح (Morning Standup)** لجميع الوكلاء.
  - قائمة **دورك اليوم** وتقارير الأسبوع.
- **دليل معماري تحليلي:** مقارنة تفصيلية وتوثيق للمسارات التشغيلية للوكلاء.

## 🚀 طرق التشغيل

### الطريقة الأولى: بنقرة واحدة (Windows)
انقر نقراً مزدوجاً على الملف:
```
launch_hq.bat
```

### الطريقة الثانية: عبر Python
افتح موجه الأوامر في هذا المجلد وشغّل:
```bash
python launch_hq.py
```
ثم توجه إلى: `http://localhost:5174/`

### الطريقة الثالثة: فتح مباشر بدون خادم
افتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح (Chrome, Edge, Firefox).

### الطريقة الرابعة: عبر خادم النظام الرئيسي
عند تشغيل خادم النظام (`python web_service.py`)، تتوفر الصفحة مباشرة على:
- `http://localhost:8000/hq`
- `http://localhost:8000/odoo-hr-hq`

### الطريقة الخامسة: عبر بيئة التطوير (Vite)
- `http://localhost:5173/`
