# نظام الذاكرة المستمرة — claude-mem (Persistent Memory)

تم تثبيت وتفعيل نظام الذاكرة الممتدة عبر الجلسات **claude-mem** (الإصدار 15.3+) في هذا المشروع والبيئة المحلية.

---

## 🧠 آلية عمل الذاكرة في المشروع

1. **الالتقاط التلقائي (Automatic Capture)**:
   - يتم تتبع أحداث الجلسات، واستدعاءات الأدوات، والقرارات المعمارية، وحلول المشاكل، والتحذيرات الأمنية عبر خطافات دورة الحياة (`hooks.json`).
   - تُلخص الملاحظات وتُخزن في قاعدة بيانات محلية SQLite مع فهرسة نصية هجينة وذكية (FTS5 + Vector Search عبر Chroma).

2. **حقن السياق المستمر (Context Injection)**:
   - في بداية كل جلسة جديدة، يتم حقن ملخصات القرارات السابقة والسياق ذي الصلة تلقائياً في سياق النموذج من خلال `<claude-mem-context>` في `GEMINI.md` و `.agents/rules/`.

3. **البحث اليدوي والاستعلام الذكي (Memory Search Tools)**:
   - يمكن في أي وقت البحث في ذاكرة المشروع عبر سطر الأوامر:
     ```bash
     npx claude-mem search "كلمة البحث"
     ```
   - أو عبر خادم MCP المربوط بالنظام (`claude-mem`) الذي يوفر أدوات:
     - `search(query, type, limit)`: البحث السريع بالكلمات المفتاحية والنوع (decision, bugfix, security_alert, sensitive).
     - `timeline(observation_id)`: استعراض التسلسل الزمني للأحداث المحيطة بملاحظة معينة.
     - `get_observations(ids)`: جلب التفاصيل الكاملة للملاحظات المحددة.

4. **لوحة التحكم والمشاهدة الحية (Web Viewer & Health)**:
   - خدمة الـ Worker تعمل محلياً على المنفذ: `http://127.0.0.1:37777`
   - يمكن فحص صحة الخدمة:
     ```bash
     npx claude-mem status
     npx claude-mem doctor
     ```
